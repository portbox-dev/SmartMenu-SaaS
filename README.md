# 🍽️ SmartMenu – AI-Powered QR Menu SaaS

Making Restaurant Menus Smarter, Simpler, and More Accessible.

<br>

# 📌 Purpose

SmartMenu is a web-based SaaS platform that helps restaurants create, manage, and share digital menus through QR codes. Restaurant owners can manage dishes, categories, prices, images, and availability, while customers can explore menus through a mobile-friendly interface.

This project was developed collaboratively as part of the HackIndia AI-First Startup Hackathon 2026.

<br>

# 🌐 Live Application

[Visit SmartMenu](https://smartmenu-webapp.ai.studio/)

<br>

# ✨ Key Features

- 🏪 Restaurant Dashboard
- 📝 Digital Menu Management
- 📱 QR Code Generation
- 🔎 Customer Menu Search and Filters
- 🥗 Dish Details and Dietary Information
- 📊 Menu Engagement Analytics
- 💡 Rule-Based AI Menu Insights
- ☁️ Supabase Cloud Integration

<br>

# 🛠️ Technology Stack

- **Frontend:** Web Technologies
- **Backend Services:** Supabase
- **Authentication:** Supabase Auth
- **Database:** Supabase
- **Storage:** Supabase Storage
- **Security:** Row Level Security (RLS)

<br>

# 🚀 Run Locally

1. Clone the repository:
   
   `git clone https://github.com/portbox-dev/SmartMenu-SaaS`

2. Navigate to the project folder:
   
   `cd smartmenu-saas`

3. Install dependencies:
   
   `npm install`

4. Configure the required environment variables.

5. Start the development server:
   
   `npm run dev`

<br>

# 🤖 AI Usage

AI-assisted development tools were used for code generation, implementation guidance, debugging, and development support. The current AI Menu Insights feature uses rule-based analysis rather than a live generative AI model.
